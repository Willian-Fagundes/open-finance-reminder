# open-finance-reminder
A open finance policy reminder

## Browser chat interface

Start the local chat server with:

```bash
python main.py
```

Open the browser at `http://localhost:7860` and ask a question. The chat history is stored in your browser tab using sessionStorage, so the conversation stays available while the tab remains open.
